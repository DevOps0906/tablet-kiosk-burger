# 01 버거 업무 규칙

> 코드 위치: `tablet-kiosk-core/apps/kiosk/lib/verticals/burger/`. 확장 지점 정의는 core `docs/08-vertical-module.md`.

## 업무 규칙

### 1. 세트 구성

- 버거를 누르면 구성 선택 (`02-set`): 단품 / 세트 / 라지세트 카드, "세트에서 +700원이면 라지" 권유 문구
- 세트 · 라지면 다음 화면 (`03-custom`)에서 1 세트 → 2 사이드 → 3 음료 → 4 재료 단계 표시
- 세트는 사이드 · 음료 단계가 **필수**, 단품은 재료 단계만
- 라지면 사이드 · 음료가 L로 바뀜
- 품절 사이드 · 음료는 자동으로 숨김

### 2. 재료 변경

- 재료 빼기는 무료(양파 · 피클 · 양상추 · 소스), 추가는 유료(치즈 +600 · 패티 +2,000 · 베이컨 +1,000)
- 장바구니 항목 아래에 변경 내용 요약 (`감자튀김 L · 콜라 L · 양파 빼기 · 치즈 추가`)
- 장바구니에서 `구성 변경`으로 다시 편집

### 3. 주문번호 · TV

- 주문번호는 매일 `001`부터 (호출 접두어 없음), 완료 화면에 크게 `317`
- **주문번호 안내 화면(TV)**: 가게 TV나 남는 모니터에서 웹 주소(`[서비스 주소]/board/<매장코드>`)를 열면 조리 중 · 완료 번호 표시
- TV 화면은 `orders.kitchen_status`를 Realtime으로 구독. 상태 변경은 사장님 화면(또는 주방 화면)에서
- 완료 화면 문구: "주문번호 안내 화면에 317이 뜨면 카운터에서 받아 가세요"

### 4. 더치페이

- N등분 화면: 인원 선택 2 · 3 · 4 · 5 · 6+, `22,800원 ÷ 3명 = 7,600원`
- 나누어 떨어지지 않는 원 단위는 마지막 결제자에게 더함
- 결제자 행: 완료 / 카드를 꽂아 주세요 / 대기

### 5. 주방 주문서

- 맨 위 `#317 매장` (2배 크기)
- 메뉴 아래 변경 내용 강조 (`· 양파 빼기 · 치즈 추가 · 감자튀김 L · 콜라 L`)
- 마지막 줄: `더치페이 3건 접수 12:31`

## 확장 지점 구현

| 확장 지점 | 버거 구현 |
|---|---|
| `theme` | 레드 테마 (메뉴 상단 바는 어두운 배경 + 앰버 탭) |
| `preset` | 추천 · 버거 · 세트 · 사이드 · 음료 · 디저트 + 위 예시 메뉴 · 세트 구성 |
| `labels` | `주문번호`, 완료 문구 "영수증 위 번호를 꼭 확인해 주세요" |
| `menuCardDecorator` | `BEST` · `NEW` 배지, `6,900원~` (세트 가격 있음 표시) |
| `itemConfigurator` | 단품 / 세트 / 라지 → 사이드 · 음료 → 재료 |
| `cartRules` | 세트 필수 단계 완료 여부 |
| `paymentHooks.afterPaid` | 주문번호 TV 등록 (`kitchen_status = received`) |
| `printBlocks.kitchen` | 재료 변경 강조 |
| `printBlocks.receipt` | 주문번호 크게 |
| `doneScreenExtras` | TV 안내 문구 |
| `setupExtras` | 주문번호 안내 화면 주소 · QR, 세트 · 라지 권유 켜기 |
| `adminExtras` | 주문번호 TV 화면 URL, 조리 상태 변경 (간이 주방 화면) |

정의하지 않은 확장 지점은 기본 구현(아무것도 안 함)을 씁니다.

## 데이터 키 (`vertical_attrs` · `vertical_data`)

| 위치 | 타입 | 뜻 |
|---|---|---|
| `menu_items.vertical_attrs.set_config` | json | 세트 가능 여부, 세트 추가금, 라지 추가금, 기본 사이드 · 음료 |
| `menu_items.vertical_attrs.toppings` | json | 빼기 가능 재료, 추가 재료 · 가격 |
| `order_items.options_snapshot` | json | 구성(단품 · 세트 · 라지) · 사이드 · 음료 · 재료 변경 |
| `orders.order_no / kitchen_status` | 공통 컬럼 | 주문번호, TV 표시 상태 (조리 중 · 완료) |

새 키를 추가하면 이 표를 먼저 고칩니다. 조회 · 집계가 많아지면 core에서 컬럼으로 승격합니다.
