# 사장님 세팅 명세 — 버거 (갤럭시탭형)

> 갤럭시탭에 앱을 설치한 사장님이 혼자 10분 안에 끝내는 5단계입니다. 공통 구조는 같고, 3 · 5단계에 업종 항목이 붙습니다.

## 1 사장님 시작

- 디자인: [`set-01-start`](../screenshots/set-01-start.png)
- 참고: docs/00 D2 (로그인 방식), D3 (기기 등록)

**구성**

- 휴대폰 번호 인증으로 사장님 계정 만들기 / 이미 계정이 있으면 로그인 후 이 태블릿을 추가 기기로 연결
- 준비물 안내: 사업자등록번호(카드 가맹), 블루투스 카드 리더, 영수증 프린터 — 나중에 넣어도 됨
- 왼쪽 5단계 진행 표시, 하단 "막히면 원격으로 도와드려요 [고객센터 번호]"

**예외**

- 인증번호 오류 · 시간 초과
- 이미 다른 매장에 연결된 기기

## 2 매장 정보

- 디자인: [`set-02-store`](../screenshots/set-02-store.png)
- 참고: core docs/08 5장

**구성**

- 가게 이름, **업종 선택**(식당 / 카페 / 버거 · 분식 / 기타)
- 로고 올리기(없으면 가게 이름 글자), 대표 사진 찍기(시작 화면 배경)
- 주문 방식(매장 · 포장), 손님 호출 방식
- 오른쪽 손님 시작 화면 미리보기 — 바꾸면 바로 반영

**예외**

- 업종 `기타`는 현재 미지원 → "곧 지원 예정" 안내 (결정 필요)
- 업종 변경 시 3단계 기본 분류가 바뀐다는 확인

## 3 메뉴 등록

- 디자인: [`set-03-menu`](../screenshots/set-03-menu.png)
- 참고: 업종 `preset` · `setupExtras`

**구성**

- 왼쪽: 분류 칩(개수 표시) + 메뉴 목록, 오른쪽: 선택한 메뉴 편집
- 메뉴판 사진으로 한 번에 등록 (2차 — OCR · AI 인식, MVP는 버튼 숨김 또는 "준비 중")
- 사진 찍기, 메뉴 이름, 가격, 업종 전용 항목(아래 업종 표)
- 품절 표시, 주문서 출력 대상
- **버거 항목**: 단품 · 세트(+2,700) · 라지(+700) 가격, 재료 빼기(무료) · 재료 추가(유료) 목록, "사이드 · 음료는 세트 공통 저장"

**예외**

- 가격 0원 · 빈 이름 저장 불가
- 사진 없으면 업종 색 박스

## 4 결제 단말 · 프린터 연결

- 디자인: [`set-04-devices`](../screenshots/set-04-devices.png)
- 참고: core docs/03

**구성**

- ① 카드 결제: 사업자등록번호, 가맹 상태([VAN사]), 블루투스 카드 리더 연결 · 배터리, **테스트 결제 후 바로 취소**
- ② 영수증 프린터: 블루투스 / 와이파이 · LAN, 80mm ESC/POS, 테스트 출력
- ③ 주방 프린터: IP 자동 검색, 출력 분류, 다시 검색
- "주방 프린터가 없으면 영수증 프린터 하나로 주방 주문서까지 출력" 안내

**예외**

- 프린터 못 찾음 → IP 직접 입력
- 카드 리더 미연결 상태로 다음 진행 가능(손님 결제는 막힘)

## 5 키오스크 모드

- 디자인: [`set-05-kiosk`](../screenshots/set-05-kiosk.png)
- 참고: core docs/03 5장

**구성**

- 화면 방향(가로 추천 / 세로), 결제 방법(전체결제 · 더치페이, 더치페이 방식)
- 화면 잠금 · 복귀(앱 고정, 무입력 후 처음 화면 시간)
- 사장님 PIN 설정, 해제 방법 안내(화면 오른쪽 위 5번 탭 → PIN)
- 업종 전용 설정 (아래 업종 표)
- `키오스크 시작하기` → 잠금 진입 → 손님 시작 화면
- **버거 항목**: 버거 전용: 주문번호 안내 화면 주소 `[서비스 주소]/board/<매장코드>` + TV 연결 QR, 주문번호 매일 001부터, 세트 · 라지 권유

**예외**

- PIN 4자리 미만 불가
- Device Owner 미설정이면 화면 고정 모드로 시작하고 안내

## 수용 시나리오

- [ ] 새 태블릿에서 1→5단계를 마치고 `키오스크 시작하기` → 손님 시작 화면
- [ ] 2단계에서 업종 `버거 · 분식` 선택 → 3단계 기본 분류가 추천 · 버거 · 세트 · 사이드 · 음료 · 디저트
- [ ] 4단계 테스트 결제(즉시 취소) · 테스트 출력 성공
- [ ] 5단계 PIN 설정 후 화면 오른쪽 위 5번 탭 → PIN → 세팅 화면 복귀
