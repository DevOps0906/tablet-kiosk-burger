# 쿠폰 명세 — 버거

> 공통 규칙(시리얼 형식, 서버 함수, 불가 사유 문구)은 core `docs/06-coupon.md`. 이 문서는 버거 화면과 예시 값입니다.

## 1. 사장님 — 쿠폰 관리 대시보드

- 디자인: [`coupon-dashboard`](../screenshots/coupon-dashboard.png) (반응형 3구간, core `apps/admin/CLAUDE.md`)
- KPI: 진행 중 쿠폰 · 이번 달 발행 · 사용 · 사용률 · 쿠폰 사용 주문 매출 (**예시 데이터** 표시)
- 발행 목록: 쿠폰 이름 · 혜택 · 발행 방식 · 기간 · 발행/사용 · 상태 · 수정, 필터(전체 · 진행 중 · 종료)
- 오늘 사용 기록: 시각 · 쿠폰 · 방식(바코드 / 시리얼) · 주문번호 · 할인액
- 사용 방식 비율 막대

예시 쿠폰 목록은 `docs/02-menu-seed.md`.

## 2. 사장님 — 쿠폰 발행

- 디자인: [`coupon-create`](../screenshots/coupon-create.png)
- 예시 입력: 쿠폰 이름 `세트 1,500원 할인`, 혜택 종류 `금액 할인`, 할인 `1,500원`, 조건 `세트 1개 이상`, 기간 `2026.10.01 ~ 2026.11.30`, 1장당 1회
- 발행 방식(여러 개): 시리얼 자동 생성(CSV) · 바코드 · QR 이미지(인쇄용) · 문자(2차) · 영수증 하단 인쇄
- 미리보기: 가게 이름 · 쿠폰 이름 · 조건 · 바코드 · 시리얼 `BR24-9XTN-4KCH`

## 3. 손님 — 시리얼 입력

- 디자인: [`hw-coupon-serial`](../screenshots/hw-coupon-serial.png) (스탠드) · [`sw-coupon-serial`](../screenshots/sw-coupon-serial.png) (갤럭시탭)
- 진입: 결제 방법 화면(`05-pay-method` / `sw-05-pay`)의 `쿠폰 사용`
- 탭: `시리얼 번호 입력` (선택) / `바코드 · QR 스캔`
- 4자리 칸 3개, 32키 키패드, `전체 지움` · `⌫`
- 12자 입력 즉시 확인 → 결과 카드: `✓ 세트 1,500원 할인`, `세트 메뉴 포함 주문 · 11월 30일까지 · 1회 사용`, 주문 금액 `22,800원` · 쿠폰 할인 `-1,500원` · 결제할 금액 `21,300원`
- `취소` / `쿠폰 적용하고 결제 방법 선택`

## 4. 손님 — 바코드 · QR 스캔

- 디자인: [`hw-coupon-scan`](../screenshots/hw-coupon-scan.png) (스탠드) · [`sw-coupon-scan`](../screenshots/sw-coupon-scan.png) (갤럭시탭)
- 스탠드형: "화면 아래 스캐너에 쿠폰 바코드를 비춰 주세요", 스캐너 위치 안내(카드 단말 옆, 화면 아래)
- 갤럭시탭형: "태블릿 앞면 카메라에 쿠폰 바코드를 보여 주세요", 카메라 화면 + 모서리 표시 + 빨간 스캔 선, USB · 블루투스 스캐너도 가능
- 인식되면 시리얼 입력과 같은 결과 카드

## 5. 수용 시나리오

- [ ] `BR24-9XTN-4KCH` 입력 → 22,800원이 21,300원으로
- [ ] 같은 시리얼 바코드 스캔 → 같은 결과
- [ ] 결제 완료 후 같은 쿠폰 다시 사용 → "이미 사용한 쿠폰이에요"
- [ ] 조건 미달 주문 → 조건 안내 문구
- [ ] 결제 취소 → 쿠폰 예약 해제 → 다시 사용 가능
